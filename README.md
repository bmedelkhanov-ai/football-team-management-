# Футбол командасын басқару ақпараттық жүйесі

Бұл жоба жаттықтырушыға жаттығуларды жоспарлауға, футболшылардың қатысуын белгілеуге және команда статистикасын бақылауға көмектеседі.

## Қатысушылар
- **Жаттықтырушы:** жаттығу құру, қатысушылар тізімін қарау, қатысуды белгілеу, команда құрамын басқару, статистиканы көру.
- **Футболшы:** жаттығу кестесін көру, қатысуды растау, өз статистикасын көру, хабарлама алу.
- **Әкімші:** пайдаланушыларды басқару.

## Мақсат
Команданы басқаруды жеңілдету және жаттығу туралы ақпаратты бір жүйеге жинау.
