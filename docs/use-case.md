# Use Case сипаттамасы

## Актерлер
- Жаттықтырушы
- Футболшы
- Әкімші

## Негізгі сценарий: жаттығу құру
1. Жаттықтырушы жүйеге кіреді.
2. «Жаттығу құру» бөлімін таңдайды.
3. Жаттығу күні, уақыты және орнын енгізеді.
4. Жүйе жаттығуды сақтайды.
5. Футболшыларға хабарлама жіберіледі.

## Басқа сценарийлер
- Жаттықтырушы қатысуды белгілейді және статистиканы қарайды.
- Футболшы кестені қарап, қатысуын растайды.
- Әкімші пайдаланушыларды басқарады.
